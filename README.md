# 脱毛吧引流素材台 2.0

正式网址：https://yichu-zql.github.io/tuomaoba-content-gpt-studio-2.0/

在现有素材台上增加“创意发现 → 统一内容编辑”，保留四平台153条模板、713张画面说明及现有案例、门店资料。内容基线来自 `yichu-zql/tuomaoba-content-gpt-studio` 的 `6cb1cc4a0950df807240bb34beab3b148cae5ae9`。旧站不受影响。

## 功能与限制
- 素材台：现有模板、主题、生成、拆对标、门店与价格、图库保留；详情可进入创作台编辑。
- 创意发现：按平台、主题、角度、形式和关键词筛选，查看依据与素材需求。
- 编辑：文案、分镜、逐页文字、真实背景图、构图说明与样式集中编辑；变量统一用于预览与导出。
- 我的创作：独立草稿、本地保存、复制、导入导出；模板不被改动。
- 资料库：现有创意结构及引用案例；支持手动录入案例、上传真实图片并在编辑中调用。
- 输出：完整文案TXT、可编辑草稿JSON（含使用的本地图片）、当前画面PNG。PNG是图片与文字本地合成，非AI生图。

飞书和生图未连接；没有视频合成导出。素材台保留原有GPT接口设置，需自行配置服务端。空白创意“本地初稿”使用内置规则，非GPT。公开源码不含密钥。

历史案例、价格、活动、体验和平台说明未在本次重新核验。案例包含同行、相近业态和跨行业，不据此排名。新编辑器不自动填入历史默认价格，缺失变量显示待填。比例为可调整预设，不代表平台强制规格。

## 结构和更新入口
- `index.html`、`studio/app.js`：创意发现、编辑和资料库界面与交互。
- `studio/core.js`：筛选、变量、草稿、版本化存储、导出和词表提示。
- `studio/style.css`：设计变量、桌面与手机布局。
- `materials.html`、`app.js`：现有素材台；`studio/bridge.js`加入导航与跨页入口。
- `base.js`、`stores.js`、`content_*.js`、`playbook_*.js`：内容数据，更新无需重写布局。
- `compliance.js`：关键词词表，不等于完整合规审核。

草稿存储键为`tmb.studio2.workspace.v1`，素材台使用`tmb.studio2.legacy.*`，不覆盖同域名旧站数据，不自动迁移旧站数据。未知版本或损坏数据阻止写入。本地图片最长边压至1600像素；浏览器空间不足时明确报错，不清空已有存储。下载的草稿可重新导入。进入新编辑器时复制模板，后续两处独立编辑。

## 验证与发布
运行`node tests/check.cjs`。本地预览`node tests/serve.cjs`，支持项目子路径。自动检查配置位于`.github/workflows/check.yml`，在推送main及提交PR时运行，工作流仅申请源码读取权限。Pages沿用main分支根目录发布，与自动检查独立运行；当前尚未设置检查失败阻止部署。

流程：检查现状→本地验证→检查提交内容→提交与推送→等待Pages→正式环境复验。更新资源时同步HTML版本查询标识。回退用`git revert`对应提交后重新发布，不重写历史。

PNG依赖浏览器字体，导出后应检查长文字排版。清除浏览器数据会丢失本地内容，所需草稿可自行下载。

## 2.1 创意发现维护
- `studio/discovery.js` 按平台和内容主题提供视角、创意点与初稿结构；每主题至少5个视角，每视角3个创意点。均为待验证策划建议。
- 创意发现读取现有内容矩阵与本地行业案例；案例需提供主题与借鉴方法，提炼结果保留原来源。没有主题的旧手动案例仍在资料库，不自动归类。飞书与云端创意库未连接。
- 编辑后可生成结构预览并下载SVG；朋友圈使用短配文、独立配图及首评，不生成视频分镜。
- `studio/platforms.css` 与 `studio/icons` 维护公共置顶样式与平台识别图形。

## 2.2 页面开关与排版
`studio/app.js` 的 `DISCOVERY_ENABLED=false` 关闭创意发现路由，源码与草稿保留；恢复时还需恢复导航入口。素材台入口名称为创意素材台。公式详情采用顺序章节与四段导航；朋友圈详情复用朋友圈列表的发布预览格式。公共平台栏的置顶偏移通过实际头部高度计算。

## 小红书参考素材库（2026-10-31）
图片经网页正常浏览采集，用户授权公开参考展示。`reference-assets/xhs/manifest.json`记录作者、笔记ID、主题、文件与SHA256；`reference-assets/catalog.js`供页面读取。新增图片先确认来源与主题，再按文件内容去重并重算coverage；不可用体验图冒充路线图凑数。图片在当前平台为小红书时出现在资料库→素材库，以及编辑页→选择素材。公开图加入当前画面时复制进浏览器草稿，并保留来源，草稿导出可带走使用的图片。飞书与在线AI仍未接通。完整继承锚点见 `PROJECT_HANDOFF.md`。
